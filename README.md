# Potato/Onion Stock Frontend

React + Vite UI for the stock backend.

## Setup

```bash
npm install
npm run dev
```

Default URL:

```text
http://127.0.0.1:5173
```

The frontend calls:

```env
VITE_API_URL=http://localhost:5000/api
```

Make sure backend is running first:

```bash
cd ../backend
npm run seed
npm run dev
```

Pages included:

```text
Current Stock
Stock IN
Stock OUT
History
Parties
Payments
Adjustment
Products
```
